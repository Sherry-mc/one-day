# 普通一天 · 发作性睡病

一个用第一视角讲发作性睡病的互动网页：跟着一个中学生过完一天，从早上睁不开眼，到午休的鬼压床，到自习课上「手自己写字」。

**在线体验：** https://sherry-mc.github.io/one-day/

> 他上课睡觉，不是因为他不想学。

## 怎么看

- 手机打开链接，竖屏体验最好；戴耳机，声音是体验的一半。
- 全程点屏幕往下走，每一幕都能点「跳过」。
- 12:40 那一幕会跳到单独的「鬼压床 30 秒」，看完能回到主线。

## 里面有什么

| 时间 | 这一幕在演什么 |
|---|---|
| 06:50 | 醒了三次，前两次是假的（入睡幻觉 / 假醒） |
| 07:30 | 读课文，字一个个掉光，然后是 3 秒黑屏 |
| 10:05 | 笑了一下，身体突然软下去（情绪性猝倒） |
| 12:40 | 趴在课桌上，意识清醒但动不了（睡眠瘫痪） |
| 15:30 | 抄作业，黑屏两秒，醒来本子上多了半页字（自动行为） |
| 17:50 | 骑车还是推着走（交通事故风险约常人 6.7 倍） |
| 23:30 | 越努力越睡不着，一夜醒四次 |

## 技术

- 纯静态：两个 HTML 文件，零依赖、零构建、无外部请求。
- 所有画面用 CSS 画，所有声音用 Web Audio 现场合成，没有一张图片、一个音频文件。
- 支持 `prefers-reduced-motion`，动效敏感的人会自动走短路径。

## 关于这份作品

课程作业，用于科普，**不构成医学诊断建议**。每一幕都是模拟，真实症状因人而异、差异很大。

数据来源：人民网健康《不是"睡不醒"，是病了》2026-03-24；央广网《关注发作性睡病》2026-09-24（西安市人民医院睡眠中心）；人民日报客户端。

发作性睡病 2023 年 9 月已纳入我国《第二批罕见病目录》。如果你或身边的人出现**白天不可控地睡着、情绪激动时身体突然发软、眼皮睁不开**，请去神经内科或睡眠医学中心。
